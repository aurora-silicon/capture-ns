OpenSSL is an external dependency (Apache-2.0 in OpenSSL 3), compatible with MIT. Tract and the Rust dependency tree use the recorded lock from the pinned libDF manifest; stale workspace entries are refreshed while retaining the compatible Tract 0.21.4 set. The build preserves the actual lock and its hash and reuses the integration's lock when available. NumPy/SciPy/SoundFile/ONNX/ONNX Runtime retain their original licences; the scripts pin evaluation versions and record installed versions. Distributing dependency binaries requires preserving their notices as well as these top-level notices.

PESQ is deliberately not used: a Python wrapper's licence would not by itself establish permission for the underlying ITU implementation. DNSMOS is a model-based estimate, not a subjective listening test and not a speech-intelligibility guarantee.
